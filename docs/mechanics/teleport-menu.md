# Teleport menu (`::teleport`)

Custom server feature, not an OSRS interface. Code: `content/gameframe/.../TeleportMenu.kt`; data `teleports.tsv`; client
`pack/interfaces/teleports.if3` and `pack/cs2/script/[*,teleports_*].cs2`.

| # | Rule | Source |
|---|---|---|
| TM1 | **Same rules as a spell.** Every teleport is a `TeleportRequest` (teleports.md T7): Tele Block, Wilderness above level 20, the boss-lair delay and one cast at a time are checked at the click; the standard spellbook animation plays (T2). A refused teleport leaves the menu open; the refusal message comes from the shared handler. | teleports.md |
| TM2 | **World policy.** `::teleport` (aliases `::teleports`, `::tp`) is a CONVENIENCE command like `::home`, so a live 1:1 world's policy turns it off (commands brief §3). | D-087 |
| TM3 | **Destinations** (`teleports.tsv`, 149 rows: cities, raids, bosses, skilling, misc). Each tile is either a coordinate the repo already uses (spell, jewellery and tablet destinations, raid lobbies, boss-lair entrances; file:line in the `source` column) or the OSRS Wiki page's map pin, translated from world-map to game coordinates (npc-spawns.md SP15). Every tile was checked with `cache-dump spawn-check`; tiles on scenery or blocked floor were moved to the nearest standable tile (noted in `source`). Rooftop courses use the course's last landing tile (on the ground by the start), not the first obstacle's roof tile. Grotesque Guardians and Phantom Muspah are left out: neither page gives a location. Ids are stable (saved favourites and recents refer to them): add rows with new ids, never renumber. | `source` column |
| TM4 | **Icons** are cache sprites: Favourites `worldswitcher_stars,1`, Recent `side_icons,38`, Cities `worldmap_icon_large,0`, Raids `icon_activities_25x25,9`, Bosses `icon_activities_25x25,3`, Skilling `side_icons,1`, Misc `icon_activities_25x25,10`, Wilderness `icon_activities_25x25,2`. Bosses (and The Fractured Archive, Wintertodt, Tempoross, Fortis Colosseum) show their own `icon_boss_25x25` frame (`teleports.tsv` `icon` column), matched pixel for pixel against the OSRS Wiki's `<Boss> icon.png`; Sarachnis, Kalphite Queen and Cerberus by eye where the Wiki file differs slightly. Artio, Calvar'ion and Spindel have no icon of their own and use Callisto's, Vet'ion's and Venenatis's. Chambers of Xeric (28), Theatre of Blood (30), Tombs of Amascut (37), Vorkath (21) and Barrows (7) use the frames RuneLite names `HISCORE_CHAMBERS_OF_XERIC` etc. (gameval `SpriteID.IconBoss25x25`); that naming confirms every other assignment too. Tormented Demons and the Revenant Caves have no frame and keep the category icon. | cache archive 8; Wiki icon files |
| TM5 | **Wilderness destinations** (12, also listed together on the Wilderness tab) show their level in red and a skull warning; teleporting asks first ("<name> is in level N Wilderness. Teleport?"; above level 20 the prompt and the warning say that teleporting out is not possible there, T4). Levels are `Wilderness.realLevel` at the tile (content/pvp), computed when the table was built; Ferox Enclave is shown as safe. | wilderness.md |
| TM6 | **Search** matches every word against the name, description and category, across all categories; results are grouped under their category, name matches first. `::teleport <words>` teleports straight away when exactly one destination matches (or one is named exactly), else opens the menu on the search. | |
| TM7 | **Favourites** (right-click "Add favourite", or the button) and the last 8 **recent** destinations are saved with the account (`teleport_fav_0..3` bitsets, `teleport_recent_0..1` 16-bit ids). The menu opens on Favourites when there are any. "Last teleport" repeats the most recent one. | |
| TM8 | **Chat input.** Focusing the search box takes the keyboard from the chatbox (`chatdefault_stopinput`); closing the interface while it still has it would leave the chatbox unable to type. The server runs `chat_restore_input` whenever the teleport menu, `::commands` or the Trading Post closes. | seen in the client 2026-11-09 |
| TM9 | **Scrolling.** Selecting a row or toggling a favourite redraws the list where the player left it (`teleports_rows` keeps the scroll, `if_getscrolly`, opcode 2601); a new category or search starts at the top. Long names are shortened with ".." (`commands_fit` measures one line: a wrap width of 0 measured only the widest word). | |
