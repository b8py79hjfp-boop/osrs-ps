# Bank

Scope: the bank interface and its item rules (`content/gameframe`: `Bank`, `BankLayout`, `BankDrag`). Behaviour source for
every row is RS Mod v2 `content/interfaces/bank` (https://github.com/rsmod/rsmod, ISC; clone read at 2026-11-06), cited as
`BankInvScript:line`, `BankOpenScript:line`, `BankSettingsScript:line` (files under
`content/interfaces/bank/src/main/kotlin/org/rsmod/content/interfaces/bank/scripts/`), unless the OSRS Wiki
(https://oldschool.runescape.wiki/w/Bank, `/w/Bank_placeholder`, `/w/Banker`) is named. Component, varbit, varp and param ids
are our gameval symbols (cache 2757) and `cache-dump`; RS Mod's rev differs from ours in component numbering, so roles were
matched by name and the op lists checked with `cache-dump interface 12`. Op numbers, sub-component ids and varps were then
checked against the disassembled rev-242 client scripts (`CS n` below = cache script n, e.g. CS 278 builds a bank slot's
ops); where they differ from RS Mod the client scripts win. No code was copied (DECISIONS D-029). A button
click is one IF_BUTTON packet handled in the player's input phase of the tick it arrives in; every row's item change is one
`PlayerRef.transaction` (brief §12), sent to the client as inventory updates at the end of that tick. A count dialog ("X")
answers on a later tick and re-checks the slot, the obj and that the bank is still open before it acts.

Interfaces: `bankmain` (12) as the main modal and `bankside` (15) in side slot 3 over the backpack (the borrowing described in
gameframe-buttons.md Q1; a once-per-tick `ModalWatch` puts the backpack back). Inventories: `bank` (95, stack always, 1410
slots in the cache), `inv` (93), `worn` (94).

- **OPEN-B4b (closed by B30-B34)** except the gem bag (no bank op in CS 2576), the seed box, the herb sack and the "Empty
  containers" button (`bankmain:depositcontainers`), which do not exist yet.

- **OPEN-B5d** Buying the potion store unlock (Mixology rewards). **OPEN-B5e** Messages for too few vials / no room in the store.
  **OPEN-B5f** Where the bank opens after "forget storage tab". **OPEN-B5g** Store deposits because the store tab is open; noted

  exported as strings by the client (CS 9607 / 9610).
