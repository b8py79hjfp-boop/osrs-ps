# Core plugins that may be loaded. One fully qualified class name per line; '#' starts a comment.
# PluginManager refuses every plugin that is not listed here (core, sideloaded and external alike),
# and a missing allowlist is fatal. build.sh copies this file into the jar as
# net/runelite/client/plugins/allowlist.txt.
#
# Policy: all core plugins except those that give a PvP information advantage beyond the vanilla game, or that
# contact a third party. The server stays authoritative; this only limits information advantages.
#
# Not listed (still in the source, never loaded):
#   - chatcommands: kc/pb/hiscore lookups of other players through the RuneLite API (not provided)
#   - opponentinfo: looks up the opponent's hiscores (stat comparison, HP level), a PvP information advantage
#   - party: needs the RuneLite websocket service (not provided); shares locations and stats
#   - loginscreen: downloads login screen assets from the static host and overrides the login screen branding
#   - emojis: downloads emoji images from the static host
#   - devtools: developer tools (var/widget/script inspectors); never for players
#
# Removed from the source entirely by the patch series (they contain third-party endpoints):
#   - account: RuneLite account sign-in and cloud config sync
#   - crowdsourcing: sends game data to the OSRS Wiki
#   - discord: Discord rich presence and avatar downloads
#   - hiscore: Jagex hiscore panel (opponent stat lookups)
#   - jagexauth: Jagex Account sign-in
#   - twitch: Twitch chat integration
#   - wiki: OSRS Wiki lookups and DPS calculator
#   - xpupdater: sends stats to Wise Old Man, TempleOSRS and Crystal Math Labs
#
# Kept although they talk to the API: loottracker (cloud sync needs an account session, which cannot exist),
# slayer / raids / poh (submit own task or layout to <api>/chat, which the hub may answer with 404),
# grandexchange / itemprices (prices from <api>/item/prices.js), worldhopper / defaultworld (<api>/worlds.js).
